# 🏫 Sistema de Agendamento IFSP Itapetininga

Este projeto é um sistema web desenvolvido em **Java (Spring Boot + Thymeleaf)** para agendamento de espaços (Quadra, Estúdio e LAB Maker) do IFSP Itapetininga.

## 🚀 Tecnologias
- Java 21
- Spring Boot 3
- Maven
- Thymeleaf
- MySQL
- HTML, CSS e JavaScript

## ⚙️ Como executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/bidoia08/ifsp-agendamentos.git
2. Configure o banco de dados MySQL e o arquivo application.properties
3. Execute o projeto:
    mvn spring-boot:run
4. Acesse em: http://localhost:8080
